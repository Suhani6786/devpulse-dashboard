# DevPulse

This is my DevPulse website for the CSI 3150 assignment.

It is a simple cloud infrastructure website made using HTML and CSS.

## Files

- `index.html` - contains the main website content
- `Styles.css` - contains the styling for the website
- `README.md` - contains information about the project

## How to Run

Open the `index.html` file in a web browser.

Make sure `Styles.css` is in the same folder as `index.html`.

## Website Sections

- **Hero** - has the main heading and buttons
- **Features** - shows three DevPulse features
- **Pricing** - shows three different plans
- **Register** - has a form for email, node count, and log throughput
- **Footer** - has the copyright information and navigation links

## Features

The three features are:

- Latency Tracking
- Log Aggregation
- Auto-Remediation

## Pricing Plans

The three plans are:

- Developer
- Pro Cluster
- Enterprise Dedicated

## Form

The form asks for:

- Work Email
- Node Count
- Log Throughput

The form uses HTML5 input rules to limit the values that can be entered.

## Responsive Design

The website changes its layout when the screen becomes smaller.

The feature and pricing sections change from three columns to one column on smaller screens.
